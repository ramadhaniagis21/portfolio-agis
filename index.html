About Me

Kenali lebih dekat tentang diri saya.

Halo, saya Agis!

Saya merupakan lulusan SMK Negeri 1 Kawali jurusan Pengembangan Perangkat Lunak dan Gim (PPLG). Selama menempuh pendidikan, saya mempelajari dasar-dasar teknologi informasi, khususnya dalam pembuatan website, pengelolaan basis data, dan desain antarmuka menggunakan beberapa teknologi seperti Laravel, PHP, MySQL, HTML, serta Figma.

Saya pernah mengerjakan website profil perusahaan menggunakan framework Laravel sebagai bagian dari tugas Uji Kompetensi Keahlian (UKK). Selain itu, saya juga mengerjakan beberapa latihan dan proyek pembelajaran untuk menambah pengalaman serta memahami proses pembuatan website.

Saya memiliki ketertarikan untuk terus belajar, mengembangkan kemampuan, dan mendapatkan pengalaman baru di lingkungan kerja. Saya juga tertarik untuk berkontribusi di bidang industri manufaktur sebagai Operator Produksi dengan mengutamakan tanggung jawab, kerja sama tim, ketelitian, dan kemampuan beradaptasi.
